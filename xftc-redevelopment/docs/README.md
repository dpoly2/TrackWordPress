# Documentation

User and admin documentation for the `ts-membership` plugin + `ts-theme` theme. For technical/developer
reference (database schema, REST API, file structure), see [../ARCHITECTURE.md](../ARCHITECTURE.md) and
the plugin/theme READMEs instead — these guides are written for club administrators, parents, and
coaches, not developers.

| Guide | Who it's for |
|---|---|
| [Getting Started](GETTING-STARTED.md) | Whoever is installing and configuring the site for the first time |
| [Admin Guide](ADMIN-GUIDE.md) | Club administrators — day-to-day operation |
| [Parent Guide](PARENT-GUIDE.md) | Families — registering, the parent portal, paying fees |
| [Coach & Staff Guide](COACH-STAFF-GUIDE.md) | Coaches and staff — entering results, viewing pay |
| [Troubleshooting](TROUBLESHOOTING.md) | Common issues and fixes |

New to this system? Start with [Getting Started](GETTING-STARTED.md).
